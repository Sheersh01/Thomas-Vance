# Thomas Vance - Modern Clothing Brand Landing Page

A cutting-edge, modern landing page for the conceptual clothing brand **Thomas Vance**. This project demonstrates an immersive, visually appealing scrolling experience with dynamic image grid animations and smooth scrolling.

## 🌟 Features

- **Dynamic Scroll Animations:** Utilizes GSAP and ScrollTrigger to create an engaging effect where a grid of images scales down and disperses as you scroll down the page.
- **Smooth Scrolling:** Integrated Lenis to ensure fluid and buttery-smooth scrolling behavior, enhancing the overall premium feel of the site.
- **Modern Typography & Design:** Uses clean, large typography (Helvetica) with a minimalist aesthetic to convey a luxurious and contemporary brand identity.
- **Responsive Grid System:** The image grid is structured using Tailwind CSS for an organized layout that looks great on modern devices.

## 🛠️ Technologies Used

- **HTML5 & CSS3**
- **JavaScript (Vanilla)**
- **[Tailwind CSS](https://tailwindcss.com/)** - Utility-first CSS framework for rapid UI styling.
- **[GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/)** - For advanced, high-performance animations.
- **[ScrollTrigger](https://greensock.com/scrolltrigger/)** - GSAP plugin for scroll-based animations.
- **[Lenis](https://lenis.studiofreight.com/)** - Lightweight smooth scroll library.

## 🚀 Getting Started

To view the project locally, follow these simple steps:

1. Clone this repository:
   ```bash
   git clone https://github.com/Sheersh01/Thomas-Vance.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Thomas-Vance
   ```
3. Open `index.html` in your preferred web browser. Alternatively, you can use a local server like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code.
